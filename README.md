# Paperless-ngx AI suggestions: wrong correspondent despite a near-identical document

Standalone reproduction for Paperless-ngx **3.3.2** (official `paperlessngx/paperless-ngx` image) with AI suggestions enabled.
No API keys, GPU or network access to an LLM provider needed: the LLM and embedding
endpoints are replaced by a small, deterministic OpenAI-compatible mock
(`mockllm/server.py`, standard library only).

## Run

```bash
./run.sh        # starts Paperless + Redis + mock, uploads 25 documents, prints the result
./run.sh down   # removes containers, volumes and saved prompts
```

Requires Docker (compose v2), `curl` and `python3`. Paperless is exposed on
http://localhost:8010 (admin / admin), the mock on http://localhost:8011.

## Data (`docs/`, generated by `make_docs.py`)

| Correspondent | Documents | Relation to the target |
|---|---|---|
| Acme Domains | 1 (`acme-2025`) | Last year's invoice for the same domain renewal: nearly identical text |
| Northwind Tracking | 7 | Same invoice layout and customer, different issuer and service |
| Fabrikam Internet | 4 | Same invoice layout and customer, different issuer and service |
| Contoso Mobile | 4 | Same invoice layout and customer, different issuer and service |
| 4 others | 8 | Unrelated (clinic letters, tax notice, insurance, bank statements) |
| *(none)* | `target` | This year's Acme Domains invoice; the correct suggestion is **Acme Domains** |

All correspondents are created with matching disabled, so only the AI suggestions are involved.

## The mock

* **Embeddings:** hashed bag-of-words vectors, so similarity follows word overlap.
  `acme-2025` is by far the nearest neighbour of `target` (cosine ≈ 0.99, vs ≈ 0.85-0.88 for the others).
* **Chat:** saves every prompt to `prompts/` and answers with a `DocumentClassifierSchema`
  tool call naming **Acme Domains**:
  * `aligned`: `correspondent_ids` is Acme Domains' id as listed in the prompt.
  * `misaligned`: same names, but `correspondent_ids` is the id of the first correspondent
    candidate in the prompt. This mirrors a tool call observed from a real model
    (`matched_correspondents: ['LiveDNS']`, `correspondent_ids: [76]`, where 76 is a
    different correspondent that was also in the candidate list).

`run.sh` queries `GET /api/documents/<target>/ai_suggestions/` once per mode (with the cache
cleared) and prints the endpoint's answer, the correspondent candidates as they appeared in the
prompt, and the LLM tool call from the webserver's DEBUG log.
